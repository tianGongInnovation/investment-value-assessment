# 项目投资价值评估（investment-value-assessment）

按一套自成体系的反主流天使投资评估方法，分析商业计划书（BP）、可行性研究报告等 PPT/Word/PDF 资料，输出 100 分制带评分和一句话结论的投资价值分析报告，每条结论可溯源、可解释、可追问。

由 **天工创新坊** 开发维护，许可 **CC BY 4.0**（署名即可自由使用、修改、分发）。

## 有什么用处？

- 20 条投资负面清单逐条比对：国家支持的项目不投、靠人力的产业不投、前沿高科技不投、互联网信息类不投……命中越多，评分越低
- 八个理论支点深挖：市场是龙头（真市场还是假市场）、规模经济、产业链分析、投创新不投创造、个人与团队、立场分析、行为金融
- 输出八章节评估报告：100 分制评分 + 一句话结论 + 评估档案留底，每条判断可溯源到清单条号

## 为什么要用？

主流评估话术（赛道、护城河、估值模型）不适合早期项目的真伪判断。本方法反其道而行：先列"不能投什么"，再对剩下的人、市场、环节做白话直说的判断——判断全部有条款、案例支撑，不和稀泥。

## 如何用？

1. 本技能是为 WorkBuddy 等智能体（Agent）准备的：安装到智能体的技能目录后，把 BP/可研报告（PPT/Word/PDF）发给智能体，说"评估一下这个项目"即可
2. 也可人工阅读本仓库 `SKILL.md` 和 `references/评估标准.md`，按方法自行分析
3. 评估完成后进入追问模式：问"为什么不能投"，回答会引用清单条号和案例

## 有问题怎么办？

- 扫描件 PDF 提取不出文字 → 用 OCR 转文字后再评估（方法见 SKILL.md"有问题怎么办"一节）
- 评估标准未覆盖的新行业 / 条款冲突 / 对评分有重大异议 → 智能体会标注【需人工判断】，最终结论由你定
